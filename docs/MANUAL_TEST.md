# IntelliJ IDEA / PyCharm 手動確認

2025.1以降の両製品で確認してください。ローカルソケットを使える環境では、先に
`python3 scripts/ide_smoke.py --ide "/path/to/IDE"` を実行できます。
このテストの成功とは別に、以下のGUI操作を確認します。

1. `python3 scripts/build.py --test` でZIPを作り、Plugins → Install Plugin from Diskでインストールします。
2. プロジェクトを開き、Settings → Tools → Undo Treeでgroup delayを0にします。Tree displayがEmacs ASCII、Visualizer keybindingsがEmacsであることを確認します。新しい空のテキストファイルを開きます。
3. `A`、`B`の順に入力して本文を`AB`にします。Tools → Undo Tree → Visualize Historyを実行し、**ツリーをクリックせずに**`p`を押します。本文が`A`になり、エディタに`p`が入力されないことを確認します。`n`で`AB`、Control+Pで`A`に戻します。エディタをクリックして`C`を入力し`AC`にします。ツリーの`A`に対応する状態に、`AB`と`AC`の両方の枝が残ることを確認します。
4. `A`の状態へ戻して右の枝を選びます。選択だけでは本文が`A`のままであること、Redoで以前の`AB`へ進めることを確認します。各ノードをクリックして枝をまたいだ復元も確認します。
5. `s`でSelectを有効にしてp/n/b/f・Control+P/N/B/Fで移動します。本文が変わらず、Enterで初めて選択状態に変わりSelectを終了することを確認します。PageUp/PageDownと,/.がSelect中は10状態移動することも確認します。
6. `d`でツリー下部の差分を表示します。Select中は選択状態と現在本文、それ以外は親状態と現在本文が表示され、移動に追従することを確認します。差分の表示後もツリーをクリックせずp/nで操作できること、`d`で非表示にできることを確認します。
7. `v` / `t`で表示を切り替えます。グラフィカル表示とASCIIが同じ分岐を表し、日本語・絵文字を含む本文も正しく復元することを確認します。表示を切り替えた直後もp/nが働くことを確認します。ASCIIのo/x/s/レジスタ文字と、選択枝の太字表示も確認します。
8. Registerで`r`へ登録し、別の状態からRecallで`r`を復元します。ファイルを保存し、現在状態のsaved表示を確認します。
9. Visualize Historyを改めて実行し、その時点の本文を覚えます。古い状態へ移動してAbortで開始時本文へ戻ることを確認します。Q / Escapeは現在本文を保持して閉じることを確認します。
10. 保存してファイルを閉じ、再び開きます。過去の枝が残ることを確認します。IDEを終了・再起動して同じ確認をします。外部で本文を変更した場合は、不一致の履歴を読み込まないことを確認します。
11. 2ファイルを交互に編集し、履歴が混ざらないことを確認します。読み取り専用ファイルの復元ではIDEの書き込み確認が働くことを確認します。
12. IDEの通常Undo/Redoも使用し、例外が出ないことを確認します。グループが異なる場合に新しい状態として残る動作は仕様です。通常キーをプラグインへ割り当てた場合の枝保持も確認します。
13. Settingsで既定をGraphical / Standardへ変更して再表示し、反映されることを確認します。Standardではp/n/b/f・Control+P/N/B/FをUndo Treeが処理しないことを確認します。Emacs ASCII / Emacsに戻し、IDE再起動後も設定が維持されることを確認します。エディタにフォーカスを戻したとき、通常の文字入力・IDEキーがプラグインに横取りされないことも確認します。
14. 保存状態やレジスタを途中に作り、Control+Up/Down、Alt+Shift+[ / ]でそこに停止することを確認します。q / Abortで閉じた後、エディタへ文字入力できることを確認します。

IDEログの`dev.undotree`に起因する例外、ツリーと本文の不一致、保存後の枝消失があれば不合格です。
